Why it is safe

  • Renewal runs beside the stage. The stage is never paused. A durable timer races it, so a 12-hour polling step, a long activity and a sub-orchestration are all covered the same way.
  • The schedule ignores stage boundaries. The next renewal is due a fixed interval after the last one, whichever stage is running.
  • A renewal only extends a lease the run still holds. It never takes a free one, because a run that lost its lease may already have overlapped with another.
  • When in doubt, stop. If the next attempt would come after the lease could expire, the run throws instead of running unprotected.
  • Cancel what you don't need. When the stage wins, the pending timer is cancelled, because an outstanding timer would keep the orchestration from completing.
